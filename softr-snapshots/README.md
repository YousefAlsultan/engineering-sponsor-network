# Softr source snapshots

These files are **exact current source snapshots** from the Engineering Sponsor Network Vibe Coding blocks.

They are intentionally kept close to the Softr source rather than cleaned up, because they are the visual/behavioral reference for a standalone rebuild.

Softr-specific imports such as `@/lib/datasource` will not work in a normal Next.js project until translated.

Do not edit these snapshot files when building the standalone version. Copy/translate them into a separate implementation directory so the original reference remains intact.

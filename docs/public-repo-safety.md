# Public repository safety

This repository is currently public.

## Never commit
- API keys
- OAuth secrets
- Notion integration tokens
- Softr private credentials
- SMTP/password credentials
- private applicant data
- private moderator notes
- non-public sponsor contact lists

## Safe to commit
- UI/source snapshots without credentials
- product documentation
- schemas/field names
- public visual URLs already used by the site
- implementation instructions

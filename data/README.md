# Public sponsor export

Read-only export of 24 published, verified listings from the existing Engineering Sponsor Network directory, captured September 18, 2026. Only public listing fields and a boolean indicating whether a delivery route exists are included. Actual contact addresses, private notes and applicant information are excluded. IDs are local synthetic identifiers.

Refresh through a server-only integration using the same public field allowlist; do not place credentials or private fields in this file. This export does not automatically refresh source checks, deadlines or eligibility.
